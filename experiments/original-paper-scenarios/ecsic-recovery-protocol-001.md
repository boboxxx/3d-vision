# ECSIC pretrained recovery and receiver dependency engineering

Prelock before model loading/forward measurements. Recover the official ECSIC
Cityscapes lambda0.01 operating point named in its README; this is not a KITTI
model selection or the unknown Cao adaptation. Source revision
696f4ae4f250bb1fc750ae9ec23e9c98c2c7e6db. Public config SHA256
ba02cc1239b755a26ca0eb920c3014908c97c45fa210c447c47e96f7527102f8;
126636561-byte model.pt SHA256
e66b55e2f888f5d113ea6c6414640c7486280d6e18838ba77c650720a5636052.
Model StereoAttentionModelPlus,N192,M48,with published kwargs including
pos_encoding=true and both z/y context. No architecture or weight changes.

Run only on sheng CPU, CUDA hidden,2Torch/OMP/MKL threads; no optimizer,
training, GT, calibration or main validation. Load with torch.load weights_only
and strict complete state matching. Use the installed runtime without changing
its dependencies; record torch/einops/torchvision versions. Set WANDB_MODE=disabled
and load only model-related modules through a package namespace; do not execute
the official package initializer, training/test entrypoints or remote logger.
Retain byte identities of every official Python source used, config, weights
and all model state tensors before/after. Keep F8 frozen trees untouched.

Two fixed inputs: synthetic32x64 pair generated by dedicated NumPy PCG64seed1907,
and native training frame000000 left/right RGB8. No other image inspection.
Convert RGB8 toFP32[0,1], right/bottom edge-replicate pad to multiples32; no
resize or image-content-dependent crop. Derive the official64-channel Fourier
position tensor from public padded dimensions. This padding/position policy
is a declared engineering adaptation, not recovered Cao preprocessing. Original
native dimensions and padding retained for eventual transmitted framing.

For each input, compute the unchanged model's full forward as reference. Then
separately extract residual integer symbols in four dependency-ordered streams:
z_left, z_right, y_left, y_right. Test that each is the rounded residual around
its learned location; retain all symbols and reference loc/scale/reconstruction
arrays. The decode-only path receives only these integer streams, public padded
dimensions, published config and the fixed weights. It recomputes z_right
parameters from decoded z_left, both hyperdecoder features from decoded z pair,
and y_right parameters from decoded y_left. It never reads source RGB, source
encoder/hyperencoder outputs, or sender-supplied probability parameters.

Require exact equality of residual symbol tensors and all reconstructed latent
tensors within the same CPU runtime, then exact unclipped reconstructed RGB
against the reference. Fail rather than silently relax this check. Install
hooks that reject E/HE execution during receiver replay. Keep outputs unclipped;
report finite values, shapes and hashes, not favorable PSNR/AP thresholds.
Check no parameter gradients/updates, full state immutability and actual
encoder/decoder call counts. Test malformed shape/order/missing stream inputs
are rejected. Large arrays stay on the data disk; unique manifests/logs.

This stage closes checkpoint recovery and causal decoder plumbing only. Integer
fixtures are not claimed as entropy-coded bytes, estimated likelihood bits are
not LDPC payload, and no compression-ratio/AP/physical-link claim is permitted.
Actual finite-CDF coder, bounded framing, corruption handling, independent
byte-only receiver and digital integration follow under a separate prelock.
No extra measured scenes or checkpoint search if the fixed test fails.
