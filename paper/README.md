# ICC 2027 working manuscript

The editable standalone source is [icc2027.tex](icc2027.tex); the retained
workspace PDF is [icc2027.pdf](icc2027.pdf). The source was rewritten around the
stereo communication problem, system model, conditional-depth codec, and
completed evidence. Learned-codec detection AP remains explicitly pending.

The [claim/evidence map](evidence-map-001.md) is a historical evidence inventory.
Its build records describe the source at their recorded hashes; they do not
certify every later source or preview edit. IEEEtran conference formatting is
provisional until ICC 2027-specific submission rules are verified.
