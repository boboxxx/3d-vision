# 方法设计：按三维几何风险分配传输能量

当前题目暂定为 **Geometry-Risk-Aware Semantic Communication for Stereo 3D
Object Detection**。创新性仍在核验；这个题目表达的是待检验的方法。

研究问题：同一条带宽受限的无线链路中，相同视差扰动在不同距离上造成
不同的三维定位误差。资源分配能否利用这一差异，提高最终的 3D AP？

对校正后的双目，若左右主点相同，深度为 Z=fB/d。若主点不同，应使用
有效视差 d-(c_L-c_R)。小扰动下：

\[
\operatorname{Var}(Z)\approx (fB/d^2)^2\operatorname{Var}(d).
\]

这只在局部、远离零视差时成立。实际模块在离散深度网格上计算后验均值
和方差，不依赖该近似；多峰后验也能保留。后验来自发送端的可训练浅层
预测头，训练监督使用投影 LiDAR；推理时仅使用双目输入。

发送端编码初步 stereo cost volume 和 appearance feature，经过信道后，
接收端恢复这两种 latent，并运行原检测器的 stereo refinement、三维投影、
BEV 和检测头。RGB 重建不参与该新方法的解码目标。发送端的 cost volume
计算开销需要实测，不能仅用通信节省论证系统收益。

第一版采用固定布局，避免隐含的位置索引链路。几何风险记为 a_i，在线
分配非负功率 p_i，在条件高斯代理模型下求解：

\[
\min_{p_i\ge0}\sum_i\frac{a_i}{1+\rho p_i},\quad\sum_i p_i=N.
\]

KKT 条件给出 p_i=[sqrt(a_i*rho/lambda)-1]_+/rho，lambda 由二分求解。
该结论仅适用于这个代理目标。真正的检测性能必须通过固定预算的 KITTI
实验验证。Rayleigh 导频估计误差下，它属于待评估的分配启发式。

每个位置编码为 k 个复符号，每个复符号两个实数分量。编码器先令该位置
平均符号能量为 1，再乘以 sqrt(p_i)。解码器直接处理接收符号；不免费获得
发送端功率图、归一化尺度或真实信道系数。Rayleigh 通过有噪声导频估计
信道，导频的符号数和能量纳入总成本。当前设计改变编码宽度才改变带宽；
功率分配本身只改变能量分布。

决定是否保留该方法的证据是：完整检测器下，几何分配相对均匀分配和
generic importance 的 AP–channel-use 曲线，以及深度分段误差和后验校准。
原文复现、RGB JSCC 基线、发送端检测后只传框的基线均需要独立完成。
后续只有在证据支持时才扩展 token 选择、数字比特流或时序通信。

原始左右拼接代价体中的左特征沿深度重复，线性打分的左图项会在 softmax
中抵消。因此 raw_cost 分界点使用 64→16→1 的点卷积与 GELU 后验头，
允许左右证据共同影响深度概率；这只验证模型表达能力，尚未证明校准。
可选学生发送端保持原始特征接口和完整接收端，原 ResNet/neck 仅作为
冻结的训练特征教师。当前实测发送端稠密 FLOPs 下界为 12.48 G，发送端
流耗时 15.99 ms，这是早期工程计时；学生随后已完成F1/F2训练，
训练后完整链路时延待复测，尚无通信增益证据。

可选任务敏感度头输入池化后的几何与外观特征，预测每个传输位置的正值
重要性。训练监督为原生三维分类、框回归及方向损失对接收复符号的
一阶梯度平方和；排除 LiDAR 模仿、深度和二维辅助损失。目标梯度
停止传播，无二阶优化；重要性头输入停止梯度，辅助监督不改动编码器。
每帧归一化后，在对数域用 SmoothL1 拟合。推理使用预测重要性，
没有标签或梯度教师。geometry_task 将其与深度方差相乘后求同一功率
代理问题；这是待实验验证的启发式。相同预测头及监督可在
uniform/geometry/task 消融中开启，控制训练容量和额外监督成本。
完整 GPU 反传验证 63 个新参数张量梯度有限。后续 F0 实际完成3340次
更新，但经独立重算的留出集通信检测AP接近零；同一学生去掉通信后
Car3D AP仍为零。随后F1学生特征预训练完成五个epoch、16700次更新，
全部原状态保持不变并通过独立审计。同372帧无通信Car Moderate 3D
AP_R40提升至11.0029%，距原检测器同集99.8629%仍很远。此结果仅支持
进一步探索学生任务适配。随后F2完成一轮3340次原生任务更新，接收端
原参数与BN仍冻结；严格重算无通信Car Moderate AP达到42.3195%。
三维/深度/二维/LiDAR模仿及特征辅助损失均保留，不能称作纯3D损失消融。
这些探索训练预算不同，尚未证明通信收益或主验证集泛化。
尚无证据支持新方法收益。代理风险的数学边界见
[risk-proxy-scope.md](risk-proxy-scope.md)，候选创新与证据缺口见
[novelty-gates.md](../literature/novelty-gates.md)。
